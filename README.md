# Banckend Proyecto 1 Gimnasio
## Teoria de Sitemas 1
## Stack Tecnologico
Spring Boot 4

# Comandos
## dev: 
```
docker compose -f docker-compose.dev.yml up --build
```
## build:
```
docker compose up --build
```

## run:
```
docker compose up
```

## stop:
```
docker compose -f docker-compose.dev.yml down
docker-compose down
```
